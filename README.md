# AUCTORITAS

Inventario psicológico: **18 preguntas** (5 respuestas cada una) + ranking de valores + **15 arquetipos**.

APIs:
- [Open Library](https://openlibrary.org)
- [OpenAlex](https://openalex.org)
- [REST Countries](https://restcountries.com)
## Cómo se mide

18 ítems × 5 opciones + jerarquía de 5 valores. Vector de 10 rasgos. El match es analogía de estilo, no un diagnóstico clínico.
